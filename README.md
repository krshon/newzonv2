
# NEWZON 🗞️

NEWZON is a full-stack web project that uses AI and NLP to analyze news content.
It focuses on **political bias detection 🧠**, **article summarization ✍️**, and an **AI reel module 🎬** for transcribing and labeling audio/video content.
Built using **Python (Flask)**, **JavaScript**, and **transformer-based models**, with emphasis on real-world APIs and clean project structure.
